# mini-agent

A minimal Python agent project skeleton managed with [uv](https://docs.astral.sh/uv/).

## Requirements

- Python 3.12+
- uv

## Quick start

```bash
uv sync
uv run mini-agent
```

The entry point is `src/mini_agent/__init__.py` and currently prints `Hello from mini-agent!`.

## Project layout

```text
.
├── pyproject.toml
├── .python-version
└── src/mini_agent/__init__.py
```
